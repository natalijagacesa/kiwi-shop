# KiwiShop

Višestranični sajt fiktivne online prodavnice (odeća, tehnika, proizvodi za dom), rađen kao
domaći zadatak iz HTML-a, CSS-a i JavaScript-a na Fakultetu organizacionih nauka.

**Autor:** Natalija Gaćeša

> Napomena: KiwiShop je izmišljena prodavnica napravljena za potrebe zadatka.
> Podaci o osnivanju, broju kupaca i dostavi nisu stvarni.

## Stranice
- `index.html` – početna (hero sekcija, tri kartice sa prednostima)
- `about.html` – o nama
- `gallery.html` – galerija proizvoda sa filtriranjem po kategoriji (kartice se generišu JavaScript-om)
- `contact.html` – kontakt forma sa potvrdom slanja

## Šta je korišćeno
- Semantički HTML5, meta tagovi (SEO), `aria` atributi za pristupačnost
- CSS promenljive, grid raspored, media query-ji, animacije (`fade-in`, `pulse`, `float-up`)
- JavaScript: burger meni, filtriranje proizvoda po kategoriji, obrada forme

## Pokretanje
Sajt nema server deo. Preuzmi ceo repozitorijum (**Code → Download ZIP**), raspakuj ga i otvori
`index.html` dvoklikom. Fajlovi moraju da ostanu u istom rasporedu foldera (`css/`, `js/`, `images/`).
